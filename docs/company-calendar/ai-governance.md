# AI governance — future phase

This release has deterministic attention rules only. No LLM extraction, executive brief, natural-language query or candidate inbox is implemented. The app's existing AI gateway remains separate; calendar records are not supplied to it by this module.

Phase 4 must retrieve through the calendar visibility predicate; preserve provenance, confidence and model/prompt version; validate structured date candidates; keep candidates separate until a human approves; refuse inferred statutory deadlines; treat source text as untrusted data; never expose HR/private data through company-wide retrieval. External messages and changes to authoritative deadlines remain explicit approved writes. A model outage must leave core calendar operations available.
